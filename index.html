🏥 Nearby Hospitals

Search a location or use your current location to find nearby hospitals.

    Open/closed status is computed from OpenStreetMap's opening_hours data, which is often missing or incomplete — treat it as a hint, not a guarantee. Insurance info comes from the local insurance-data.json file (sample data) — edit it with real information for hospitals you care about, or verify by calling the hospital. Review summaries (in each hospital's popup) show "Coming soon" until entries are added to reviews-data.json. The insurance dropdown only matches hospitals already listed in that file — everything else still shows up, just unmarked. Distance is shown only after using "Use my location" (miles in the US, km elsewhere), not for typed searches. A bare city name can occasionally match a same-named small town instead of the place you meant (e.g. "Madrid" vs. a town called Madrid, Iowa) — add the country for a sure match, e.g. "Madrid, Spain". "Type of care" filters by facility type (general, pediatric, psychiatric, cancer, etc.) for hospitals already listed in insurance-data.json — everything else shows as general by default. Each hospital's popup may also show a rating breakdown, common review topics, and a link to live ER wait times, when that data is available.
